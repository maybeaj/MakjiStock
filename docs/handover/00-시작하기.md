# 막지스톡 인계 — 시작하기

> 2026-10-07 기준. 이 폴더(`docs/handover/`)는 막지스톡을 처음 넘겨받는 사람이 **어디서부터 무엇을 읽으면 되는지**를 안내합니다. 세부 내용은 원본 문서로 연결만 하고, 여기서 다시 쓰지 않습니다.

## 막지스톡은 무엇인가

막지 자사몰 빵의 할인가를 **하루 두 번(06:00·16:00)** 바꿔, 주식 시세 화면처럼 보여주는 모바일 웹앱입니다.

- **왜**: 자사몰 손님은 아침에 둘러보고 저녁에 삽니다. 오전 로그인은 많은데 결제는 8%뿐입니다. "지금 사야 할 이유"를 만들려고 가격을 시세처럼 움직입니다.
- **어떻게**: 네이버 검색 관심도와 원/달러 환율로 할인율을 계산해 Cafe24 몰 판매가에 반영합니다. 손님은 오전가를 하루 한 번 **잠그거나**, 다음 가격이 오를지 내릴지 **예측**해 할인코드를 받습니다.
- **누가**: 가입 없이 들어오는 모바일 손님. 결제와 회원은 Cafe24가 맡고, 이 앱은 가격 계산과 잠금·예측만 담당합니다.

발표 자료: [3팀 기업연계 프로젝트 발표자료](../%EB%B0%9C%ED%91%9C/3%ED%8C%80_%EA%B8%B0%EC%97%85%EC%97%B0%EA%B3%84%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8_%EB%B0%9C%ED%91%9C%EC%9E%90%EB%A3%8C%28%EB%B0%9C%ED%91%9C%EC%9A%A9%29.html) (`docs/발표/`, 브라우저로 열기)

## 꼭 알고 시작할 다섯 가지

1. **문서가 서로 다르면 [PRD](../PRD-브레드마켓.md)가 기준**입니다. 날짜가 붙은 기록(`기획-정리-*.md`, 결정 리포트)은 당시 그대로 두고 맨 위에 바뀐 점만 적었습니다.
2. **산식·쿠폰 운영값은 DB(`pricing_versions`)가 정본**입니다. 코드나 JSON을 고쳐도 운영 가격은 바뀌지 않습니다. 바꾸려면 어드민 `/admin/pricing`에서 새 버전을 저장합니다.
3. **빵 목록도 DB(`products`)가 정본**입니다. 빵 추가·사진·정가·검색어는 어드민 `/admin/products`에서 바꿉니다.
4. **지금 연결된 Cafe24 몰은 데모몰(`rabbit3456`)** 입니다. 할인코드, 몰 가격, 주문 KPI가 모두 데모몰 기준입니다. 실제 몰(makji.kr)로 옮기는 절차는 [02-운영.md](02-운영.md#실제-몰makjikr로-옮길-때)에 있습니다.
5. **앱 화면은 06:00·16:00 정각에 바뀌지만, 몰 가격은 자동 작업이 도는 순간 바뀝니다**(무료 요금제에서는 최대 59분 차이). 이유와 해결책은 [03-기술.md](03-기술.md#4-가격이-바뀌는-시각)에 있습니다.
