# 할인율 결정 리포트 (산식 v1.0)

작성일: 2026-09-19 · 대상: 발표·팀 공유

## 한 줄

**원가가 내려가면 전부 돌려주고, 올라가면 절반만 나눠 진다. 그리고 정가는 절대 넘지 않는다.**

## 산식

```
검색 할인 = 검색지수 × 0.15                             (0 ~ 15%)
환율 조정 = 환율이 내리면  하락률 × 14                  (최대 +28%p)
           환율이 오르면  상승률 × 7  (= 절반만 반영)    (최대 −14%p)
총 할인율 = clamp(검색 할인 + 환율 조정, 0, 38)
판매가   = 정가 × (1 − 총 할인율 ÷ 100), 10원 단위 반올림
```

팀 합의안(검색 × 0.10, 환율 ±14)에서 바뀐 것은 셋이다.

| 바뀐 것 | 이유 |
| --- | --- |
| 환율이 **오를 때는 절반만** 반영 | 원가 부담을 고객에게 다 넘기지 않는다. 정가 초과를 없애는 핵심 장치 |
| **정가에서 멈춤** (할인율 하한 0) | 정가보다 비싸지면 "시세"가 아니라 "가격 인상"이다. 잠금·예측도 의미를 잃는다 |
| 검색 가중치 0.10 → **0.15** | 최대 15%로 숫자가 깔끔하고, 환율 상승분을 흡수할 여유가 생긴다 |

## 발표용 근거 — "가격을 흔들려는 게 아니다"

가격이 움직이는 이유를 두 개로만 제한했다. 둘 다 실제 신호다.

1. **검색지수 = 수요 신호.** 사람들이 많이 찾는 빵에 할인을 더 붙여 첫 구매를 끌어온다(모객).
2. **환율 = 원가 신호.** 원/달러가 움직이면 수입 원재료 원가가 움직인다. 16:00 오후가는 당일 환율 시가라는 **새 정보**가 들어왔기 때문에 바뀐다.

그리고 두 신호를 **고객 편에서 비대칭으로** 받는다.

- 원가가 내리면 → 전부 할인으로 돌려준다 (×14)
- 원가가 오르면 → 절반만 할인을 줄인다 (×7), 정가는 넘지 않는다

"하루 두 번 바뀐다"는 결과이지 목표가 아니다. 16:00에 새 환율이 나오니 가격도 새로 나오는 것이다. 환율을 할인 방향으로만 반영하면(검토안 F) 환율이 오른 날(44.6%)은 이 새 정보가 가격에 전혀 반영되지 않아 21%의 날은 오전가 = 오후가가 된다 — 시세라는 약속이 깨진다.

## 3개월 백테스트 (2026-06-19 ~ 09-18, 평일 65일 · 6종 · 780개 시세)

| | 팀 합의 원안 | 할인만 (F) | **v1.0 (Q2)** |
| --- | ---: | ---: | ---: |
| 정가 초과 | 9.7% | 0% | **0%** |
| 정가 그대로 | 0.8% | 0% | **0.1%** (780개 중 1개) |
| 오전가 = 오후가 | 0% | 21% | **0.8%** |
| 오전→오후 평균 변동 | 8.9% | 3.9% | **7.5%** |
| 평균 할인 | 7.8% | 12.3% | **12.1%** |
| 오전 잠금 후 저녁 구매 실제 할인 | 11.2% | 13.3% | **14.5%** |

- 오후가가 오전가보다 오른 날 52.3% → 잠금 차액 쿠폰 평균 593원.
- 상품 할인이 33%를 넘어 예측 쿠폰 5%가 줄어드는 시세는 1.5%.

## 매출 영향 (잠금 사용 저녁 구매자 기준)

| | 정가 1,000만원어치 판매 시 할인액 | 본전 판매량 (마진 40 / 50 / 60%) |
| --- | ---: | ---: |
| 팀 합의 원안 | 112만원 | +39% / +29% / +23% |
| **v1.0** | **145만원** | **+57% / +41% / +32%** |

팀 원안보다 할인이 3.3%p 많다. 그 차이가 "정가를 절대 넘지 않는다"와 "원가 상승은 절반만"의 비용이다. 신규 모객이 목표라 이 비용을 쓴다.
